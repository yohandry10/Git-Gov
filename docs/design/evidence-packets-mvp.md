# Evidence Packets MVP

Ticket: `KAN-23`

## Decision

GitGov should productize the evidence it already correlates before adding a richer AI copilot layer. The MVP creates a ticket-scoped evidence packet that can be generated by an operator, inspected in the dashboard, and downloaded as JSON with an integrity hash.

This deliberately uses the real backend routes and current database evidence. It does not require SonarCloud, Jenkins trigger-only URLs, generated SDKs, or full OpenAPI coverage.

## MVP Scope

The first packet type is `ticket`.

Endpoint:

```text
GET /evidence/packets/tickets/{ticket_id}
```

Query parameters:

```text
org_name
repo_full_name
branch
hours
```

The initial implementation uses `org_name`, `repo_full_name`, and `hours` to gather the ticket evidence. `branch` is preserved in the packet metadata and UI request shape so branch filtering can be tightened when the underlying correlation query supports it consistently.

## Export Model

The response shape is:

```json
{
  "found": true,
  "packet": {
    "packet_type": "ticket",
    "subject": "KAN-23",
    "generated_at": 1777560000000,
    "org_name": "yohandry10",
    "repo_full_name": "yohandry10/Git-Gov",
    "branch": "main",
    "period": "last_720h",
    "ticket": {},
    "commits": [],
    "pull_requests": [],
    "quality_gates": [],
    "completeness": {
      "ticket_found": true,
      "commits": 1,
      "pull_requests": 1,
      "pipelines": 1,
      "quality_gates": 1,
      "missing": []
    },
    "content_hash": "sha256-hex-without-self-reference"
  }
}
```

`content_hash` is SHA-256 over the packet JSON after removing the `content_hash` field. This makes the downloaded packet tamper-evident without making the hash recursive.

## UI

The admin dashboard includes an `Evidence Packet` panel:

- ticket ID input
- generate button
- JSON download button
- completeness counters for ticket, commits, PRs, pipelines, and quality gates
- generated timestamp, period, and short hash preview
- missing-evidence labels for partial packets

The panel is intentionally small and uses the existing control-plane store and Tauri command path.

## Follow-Ups

- Add persisted export history rows for evidence packets if auditors need packet generation history in the existing `/exports` table.
- Add PR-scoped and release-scoped packet types.
- Tighten branch filtering in `GET /evidence/packets/tickets/{ticket_id}` once the ticket-flow correlation query supports branch as a first-class filter.
- Build the AI SDK Governance Copilot over evidence packets instead of over raw scattered sources.
